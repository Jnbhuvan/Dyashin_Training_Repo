4. What is Callback function? Write an example.
Answer:
Callback Function

A callback function is a function that is passed as an argument to another function and is executed later.

Example:
function greet(name, callback) {
    console.log("Hello " + name);
    callback();
}

function message() {
    console.log("Welcome to JavaScript");
}

greet("Bhuvan", message);

Output:
Hello Bhuvan
Welcome to JavaScript

6. Whats Hoisting with Example.
Answer:

Hoisting is a JavaScript behavior where variable and function declarations are moved to the top of their scope before the code is executed.

Example:

console.log(name);

var name = "Bhuvan";

Output:
undefined

Here, the declaration of name is hoisted to the top, but its value is assigned only when the code reaches var name = "Bhuvan";.

Another example with a function:

greet();

function greet() {
console.log("Hello Bhuvan");
}

Output:
Hello Bhuvan

Function declarations can be called before they are written because they are hoisted.

7. List & explain wierd js things.
Answer:
JavaScript has some behaviors that may look strange or unexpected.

Adding Number and String

console.log(5 + "5");

Output:
55

JavaScript converts the number 5 into a string and joins them together.

Subtracting String from Number

console.log("10" - 5);

Output:
5

JavaScript converts the string "10" into a number before subtraction.

true and false with Numbers

console.log(true + true);

Output:
2

In JavaScript, true is treated as 1 and false is treated as 0 when used in mathematical operations.

Empty Array

console.log([] + []);

Output:
""

Two empty arrays are converted into empty strings and then joined.

Null and Number

console.log(null + 5);

Output:
5

JavaScript converts null to 0 when used in a mathematical operation.

Equality (==) vs Strict Equality (===)

console.log(5 == "5");
console.log(5 === "5");

Output:
true
false

== compares values after type conversion, while === compares both value and data type.

typeof null

console.log(typeof null);

Output:
"object"

This is a historical behavior in JavaScript. Although null represents the absence of a value, typeof null returns "object".

NaN

console.log("Hello" - 5);

Output:
NaN

NaN means "Not a Number". It occurs when a mathematical operation cannot produce a valid number.

These behaviors happen mainly because JavaScript performs automatic type conversion and has some historical language behaviors.

Ans:

    function wordsReverseWithFor(str){
        
        let reverse = [];

        for(w in str.split(' ')){
            reverse.push(w.split('').reverse().join(''))
        }
        
        return reverse.join(" ")
