1. Difference bw var, let and const?
Ans:
var is function-scoped and can be redeclared and reassigned.
let is block-scoped and can be reassigned but cannot be redeclared in the same scope.
const is block-scoped and cannot be reassigned or redeclared after declaration.
Generally, use let when the value changes and const when the value should remain the same.

---------------------------------------------------------------------------------------
2. What is temporal dead zone. Explain?
Ans:
Temporal Dead Zone (TDZ) is the time between entering a block and the actual declaration of a `let` or `const` variable.
During this period, the variable exists but cannot be accessed. If you try to access it before its declaration, JavaScript throws a **ReferenceError**. `var` does not have a TDZ.

3. Whats callback hell or pyramid of doom?
Ans:
Callback Hell (Pyramid of Doom) occurs when multiple callback functions are nested inside one another, making the code look like a pyramid.
It usually happens when several asynchronous tasks depend on the completion of previous tasks.
As nesting increases, the code becomes difficult to read, understand, debug, and maintain.
Promises and async/await are commonly used to avoid callback hell.

4. Example for object and array destructuring.
Ans:
Destructuring is a JavaScript feature used to extract values from arrays or properties from objects into separate variables.
// Array destructuring
let numbers = [10, 20, 30];
let [a, b, c] = numbers;
console.log(a, b, c); // 10 20 30

// Object destructuring
let student = { name: "Bhuvan", age: 20 };
let { name, age } = student;
console.log(name, age); // Bhuvan 20
